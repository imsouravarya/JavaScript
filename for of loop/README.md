# For...of Loop

This folder is about the `for...of` loop in JavaScript.

The `for...of` loop is used to iterate over iterable values such as arrays and strings.

Example:
```js
const fruits = ["apple", "banana", "mango"];

for (const fruit of fruits) {
  console.log(fruit);
}
```

Use `for...of` when you want to loop through values directly.
