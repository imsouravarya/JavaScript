# Maps

This folder is about JavaScript Maps.

A Map stores data as key-value pairs, where keys can be any type.

Common concepts:
- creating a Map
- adding values with set()
- reading values with get()
- checking entries with has()
- iterating over a Map

Example:
```js
const user = new Map();
user.set("name", "Sourav");
console.log(user.get("name"));
```
